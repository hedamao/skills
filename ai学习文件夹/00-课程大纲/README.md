## 📖 学习建议

1. **按顺序学习**：每一课都是下一课的基础，建议从第 1 课开始
2. **多做笔记**：遇到不理解的概念可以标记，后续课程会逐步深入
3. **动手实践**：第 8 课介绍了很多免费工具，建议边学边用
4. **不要着急**：AI 是一个庞大的领域，慢慢理解就好
