# 第 7 课：Skill（技能）功能概念详解

> 🎯 **学习目标**：理解什么是 AI Skill（技能），它和 MCP 有什么关系，以及如何用 Skill 让 AI 变得更专业

---

## 一、什么是 Skill？

### 1.1 通俗定义

**Skill（技能）** = 教给 AI 的一套**专业操作指南**，让它在特定领域变得更专业。

### 1.2 生动类比

```
AI 大模型 = 一个聪明的"通才"毕业生 🎓
  → 什么都懂一点，但不是专家

Skill  = 给这个毕业生的"培训手册" 📖
  → 教他如何像专家一样完成特定任务

┌──────────────────────────────────────────┐
│  没有 Skill 的 AI：                       │
│  "我知道什么是代码审查，让我试试..."       │
│  → 可能遗漏重要检查项                     │
│                                          │
│  有 Skill 的 AI：                         │
│  "根据培训手册，代码审查需要检查这 10 项"   │
│  → 按照专业流程系统地完成                  │
└──────────────────────────────────────────┘
```

## 二、Skill 的结构

### 2.1 一个 Skill 包含什么？

```
一个 Skill 文件夹 📂
│
├── SKILL.md           ← 核心：技能说明书（必须有）
│   ├── 名称和描述     ← 这个技能叫什么、干什么
│   ├── 使用场景       ← 什么时候使用
│   ├── 操作步骤       ← 具体怎么做
│   └── 注意事项       ← 易错点和最佳实践
│
├── scripts/           ← 可选：辅助脚本
│   └── helper.py
│
├── examples/          ← 可选：参考示例
│   └── example.md
│
└── resources/         ← 可选：额外资源
    └── template.txt
```

### 2.2 SKILL.md 示例

```markdown
---
name: 代码审查专家
description: 系统化地审查代码质量，找出潜在问题
---

# 代码审查技能

## 使用场景
当用户要求审查代码时使用此技能

## 审查步骤
1. 先理解代码的整体结构
2. 检查代码风格和规范
3. 检查是否有安全漏洞
4. 检查性能问题
5. 检查错误处理是否完善
6. 给出改进建议

## 输出格式
- 使用表格列出所有发现的问题
- 按严重程度排序
- 给出具体的修复建议
```

## 三、Skill vs MCP：有什么区别？

这是初学者最容易混淆的概念，让我们来明确区分：

### 3.1 核心区别

| 对比项 | Skill（技能） | MCP（协议） |
|-------|-------------|------------|
| **是什么** | 操作指南、行为规范 | 通信标准、连接协议 |
| **类比** | 📖 培训手册 | 🔌 USB 插头 |
| **作用** | 教 AI "怎么做" | 让 AI "能做到" |
| **内容** | 步骤、规则、模板 | 工具、数据、API |
| **形式** | Markdown 文件 | 服务器程序 |

### 3.2 它们的关系

```
打个比方：一个厨师做菜

Skill（菜谱） 📖：
  "先热锅，再放油，然后......"
  → 告诉厨师做菜的步骤和方法

MCP（厨具接口） 🔌：
  灶具连接、冰箱接口、料理机接口
  → 让厨师能使用各种厨具和获取食材

两者配合：
  厨师（AI）看着菜谱（Skill），
  使用各种厨具和食材（通过 MCP 连接），
  做出一道好菜（完成任务）
```

### 3.3 更直观的对比

```
场景：AI 帮你做数据分析

Skill 提供的是"方法论"：
  ┌─────────────────────────────┐
  │ 1. 先理解数据结构            │
  │ 2. 检查数据质量              │
  │ 3. 进行探索性分析            │
  │ 4. 生成可视化图表            │
  │ 5. 撰写分析报告              │
  └─────────────────────────────┘

MCP 提供的是"工具和数据"：
  ┌─────────────────────────────┐
  │ 📁 文件读取 → 获取数据文件    │
  │ 💻 代码执行 → 运行分析脚本   │
  │ 📊 图表工具 → 生成可视化     │
  │ 📝 文档工具 → 保存报告       │
  └─────────────────────────────┘
```

## 四、Skill 的实际用途

### 4.1 常见的 Skill 类型

| Skill 类型 | 用途 | 示例 |
|-----------|------|------|
| 🔍 **代码审查** | 系统化审查代码质量 | 检查安全漏洞、性能问题 |
| 📝 **文档编写** | 按规范写技术文档 | API 文档、用户手册 |
| 🧪 **测试生成** | 自动生成测试用例 | 单元测试、集成测试 |
| 🏗️ **架构设计** | 按最佳实践设计系统 | 微服务架构、数据库设计 |
| 📊 **数据分析** | 规范化的数据分析流程 | 销售分析、用户行为分析 |
| 🔧 **问题排查** | 系统化诊断和修复问题 | 服务器故障排查 |
| ✍️ **Prompt 优化** | 优化用户写的 Prompt | 让 AI 输出更精准 |

### 4.2 Skill 如何提升 AI 效果

```
没有 Skill：
  用户："帮我审查这段代码"
  AI："这段代码看起来不错，但有几个小问题..."
  
  ❌ 可能遗漏重要问题
  ❌ 缺乏系统性
  ❌ 输出格式不规范

有 Skill：
  用户："帮我审查这段代码"
  AI（调用代码审查 Skill）：
  
  ┌─────────────────────────────────┐
  │ 📋 代码审查报告                  │
  ├─────────────────────────────────┤
  │ ⚠️ 严重问题（2个）               │
  │   1. SQL 注入风险 - 第 23 行    │
  │   2. 密码明文存储 - 第 45 行    │
  │                                 │
  │ ⚡ 性能问题（1个）               │
  │   1. N+1 查询问题 - 第 67 行    │
  │                                 │
  │ 💡 改进建议（3个）               │
  │   1. 添加输入验证               │
  │   2. 使用连接池                 │
  │   3. 增加错误日志               │
  └─────────────────────────────────┘
  
  ✅ 全面系统
  ✅ 分类清晰
  ✅ 格式规范
```

## 五、Skill、MCP、Agent 的关系全景图

```
┌────────────────────────────────────────────────┐
│              AI 智能体 (Agent)                  │
│                                                │
│    🧠 大模型（思考核心）                        │
│     │                                          │
│     ├── 📖 Skill（技能指南）                    │
│     │    "按照这个步骤来做"                      │
│     │                                          │
│     ├── 🔌 MCP（连接协议）                      │
│     │    "通过这个接口获取工具和数据"             │
│     │    ├── 🔧 MCP Server A（文件操作）        │
│     │    ├── 🔧 MCP Server B（数据库）          │
│     │    └── 🔧 MCP Server C（搜索）            │
│     │                                          │
│     └── 💾 记忆系统                             │
│          "记住之前做过什么"                      │
│                                                │
└────────────────────────────────────────────────┘

总结：
  Agent = 大模型 + Skill + MCP + 记忆
  
  - 大模型提供"智力"
  - Skill 提供"方法论"
  - MCP 提供"工具和数据访问"
  - 记忆提供"经验积累"
```

## 六、如何创建自己的 Skill？

### 6.1 创建步骤

```
Step 1：明确技能目标
  → 这个 Skill 是做什么的？
  → 什么时候应该用？

Step 2：编写 SKILL.md
  → 写清楚名称和描述
  → 列出详细的操作步骤
  → 定义输出格式

Step 3：准备辅助资源（可选）
  → 添加脚本、模板、示例

Step 4：测试和优化
  → 用 AI 实际执行这个 Skill
  → 根据结果调整步骤
```

### 6.2 编写好 Skill 的技巧

| 技巧 | 说明 |
|------|------|
| ✅ 步骤要具体 | "检查 SQL 注入" 比 "检查安全问题" 更好 |
| ✅ 给出示例 | 展示期望的输出格式 |
| ✅ 说明边界 | 明确什么时候用、什么时候不用 |
| ✅ 定义输出格式 | 使用表格、清单等结构化格式 |
| ❌ 避免太笼统 | "做好这件事" 不是好的 Skill |
| ❌ 避免太复杂 | 一个 Skill 聚焦一个领域 |
