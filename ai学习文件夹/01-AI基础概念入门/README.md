# 第 1 课：AI 基础概念入门

> 🎯 **学习目标**：了解什么是人工智能，它的发展历史，以及当今 AI 的核心分支

## 一、什么是人工智能（AI）？

### 1.1 通俗定义

**人工智能（Artificial Intelligence，简称 AI）**，就是让计算机像人一样"思考"和"行动"的技术。

想象一下：
- 你对手机说"明天北京天气怎么样"，手机立刻回答你 —— 这就是 AI
- 你拍了一张花的照片，手机告诉你这是什么花 —— 这也是 AI
- 你用 ChatGPT 写一封邮件 —— 这更是 AI

### 1.2 AI 能做什么？

| 能力 | 举例 | 日常场景 |
|------|------|---------|
| 🗣️ 理解语言 | 听懂你说的话并回答 | Siri、小爱同学 |
| 👀 识别图像 | 认出照片中的人脸 | 手机解锁、美图秀秀 |
| 📝 生成内容 | 写文章、画画、编程 | ChatGPT、Midjourney |
| 🎯 做出决策 | 推荐你喜欢的视频 | 抖音、Netflix |
| 🎮 玩游戏 | 下围棋打败世界冠军 | AlphaGo |

## 三、AI 的核心分支

### 3.1 机器学习（Machine Learning）

**类比**：教小孩认字 📖

- 你给小孩看很多猫的图片，告诉他"这是猫"
- 看了足够多之后，小孩就能自己认出猫了
- 机器学习就是这样 —— 让计算机从大量**示例**中学习规律

### 3.2 深度学习（Deep Learning）

**类比**：升级版的学习方式 🧠

- 深度学习模仿了人类大脑的神经网络
- 它有很多"层"来处理信息（就像大脑的不同区域）
- 处理的数据越多、层数越多，就越聪明

```
输入层      隐藏层（多层）     输出层
  ●  ───→  ● ● ● ● ●  ───→  ●
  ●  ───→  ● ● ● ● ●  ───→  ●
  ●  ───→  ● ● ● ● ●  ───→  ●
  
 图片       特征提取          结果
"一只猫"   毛发、耳朵...    "猫 95%"
```

### 3.3 自然语言处理（NLP）

**类比**：让计算机"懂人话" 💬

- 理解人类的语言（中文、英文等）
- 翻译、摘要、问答、写作都属于 NLP
- **ChatGPT 就是 NLP 的巅峰之作**

### 3.4 计算机视觉（Computer Vision）

**类比**：给计算机装上"眼睛" 👁️

- 让计算机能"看懂"图片和视频
- 人脸识别、自动驾驶、医学影像分析

### 3.5 生成式 AI（Generative AI）

**类比**：会"创作"的 AI 🎨

- 不仅能分析数据，还能**创造新内容**
- 写文章、画图、编曲、写代码
- 这是当前最热门的 AI 方向！

## 四、AI、机器学习、深度学习的关系

```
┌─────────────────────────────────────────┐
│           人工智能（AI）                 │
│   ┌─────────────────────────────────┐   │
│   │      机器学习（ML）              │   │
│   │   ┌─────────────────────────┐   │   │
│   │   │   深度学习（DL）         │   │   │
│   │   │                         │   │   │
│   │   │   大语言模型（LLM）      │   │   │
│   │   └─────────────────────────┘   │   │
│   └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

- **AI** 是最大的概念，包含一切让机器变智能的技术
- **机器学习** 是 AI 的一个分支，通过数据学习
- **深度学习** 是机器学习的一个分支，使用神经网络
- **大语言模型（LLM）** 是深度学习在语言领域的应用

## 五、为什么 AI 突然这么火？

三个关键因素同时成熟了：

| 因素 | 说明 |
|------|------|
| 💾 **数据** | 互联网产生了海量数据（大数据） |
| 💻 **算力** | GPU/TPU 等芯片让计算速度飞升 |
| 📊 **算法** | Transformer 等新算法大幅提升效果 |

> 💡 **一句话总结**：有了足够的数据"喂养"，足够强大的硬件"运转"，以及足够聪明的算法"学习"，AI 就爆发了。
