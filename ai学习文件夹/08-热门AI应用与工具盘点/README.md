## 三、图像生成类

| 产品 | 特点 | 价格 | 适合场景 |
|------|------|------|---------|
| **Midjourney** | 画质顶级、风格优美 | 付费（$10/月起） | 设计、插画、概念图 |
| **DALL-E 3** | 与 ChatGPT 集成、理解力强 | ChatGPT Plus 内含 | 快速生成、文字描述准确 |
| **Stable Diffusion** | 开源、可本地运行 | 免费开源 | 批量生成、高度定制 |
| **通义万相** | 中文提示词支持好 | 免费 | 中文用户、海报设计 |
| **可图** | 快手出品、简单易用 | 免费 | 快速生成、日常使用 |

### 图像生成的原理（简版）

```
用户输入文字描述：
  "一只戴墨镜的柴犬坐在沙滩上喝椰汁"
        ↓
AI 理解语义：
  - 主体：柴犬
  - 配饰：墨镜
  - 场景：沙滩
  - 动作：喝椰汁
        ↓
扩散模型生成图像：
  从噪声 → 逐步还原 → 清晰图片
        ↓
输出：一张符合描述的图片 🖼️
```

## 七、AI 搜索类

| 产品 | 特点 | 与传统搜索的区别 |
|------|------|----------------|
| **Perplexity** | 最火的 AI 搜索引擎 | 直接给答案，附带来源链接 |
| **秘塔搜索** | 国内 AI 搜索 | 中文搜索体验好，无广告 |
| **SearchGPT** | OpenAI 做的搜索 | 与 ChatGPT 结合 |

### AI 搜索 vs 传统搜索

```
传统搜索（Google/百度）：
  你搜"失眠怎么办"
  → 给你 10 个网页链接
  → 你需要自己点击、阅读、总结

AI 搜索（Perplexity/秘塔）：
  你搜"失眠怎么办"
  → 直接给你一段总结好的答案
  → 包含具体建议和注意事项
  → 标注了信息来源方便验证
```
