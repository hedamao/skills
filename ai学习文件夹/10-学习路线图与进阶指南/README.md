## 二、Level 1：日常用户

### 2.1 核心技能：提示词工程

学会写好 Prompt 是使用 AI 最重要的技能！

#### 基础 Prompt 技巧

| 技巧 | 差的 Prompt ❌ | 好的 Prompt ✅ |
|------|-------------|-------------|
| 明确角色 | "帮我写邮件" | "你是一位职场沟通专家，帮我写一封..." |
| 提供背景 | "翻译这句话" | "这是一篇医学论文中的术语，请翻译并解释..." |
| 指定格式 | "总结这篇文章" | "用 3 个要点总结这篇文章，每点不超过 50 字" |
| 给出示例 | "写个标题" | "参考'如何用 AI 提升效率'这种风格，写..." |
| 限定范围 | "告诉我关于 AI" | "用 200 字，向完全不懂技术的人解释什么是 AI" |

#### Prompt 模板

```
角色 + 背景 + 任务 + 格式 + 限制

例如：
  你是一位（资深数据分析师），         ← 角色
  我有一份（上个月的销售数据），       ← 背景
  请你（分析销售趋势并找出问题），     ← 任务
  以（表格 + 图表建议）的形式呈现，   ← 格式
  重点关注（环比变化超过 10% 的品类）  ← 限制
```

## 三、Level 2：进阶用户

### 3.1 高级 Prompt 技术

| 技术 | 说明 | 示例 |
|------|------|------|
| **思维链** | 让 AI 一步步推理 | "请一步步分析这个问题" |
| **角色扮演** | 让 AI 扮演专家 | "你是一位 10 年经验的架构师" |
| **多轮迭代** | 逐步优化结果 | "很好，但请更详细地说明第 3 点" |
| **自我反思** | 让 AI 检查自己 | "回顾你的回答，有没有遗漏？" |
| **对比分析** | 多角度思考 | "列出这个方案的优缺点" |

### 3.2 使用 AI Agent

```
初级玩法：
  → 在 Coze/扣子 上搭建简单 Bot
  → 使用 ChatGPT 的 GPTs 功能
  → 给 Bot 设定专门的角色和任务

进阶玩法：
  → 配置 MCP Server 连接外部工具
  → 创建自定义 Skill
  → 构建多步骤工作流
  → 使用 Dify 搭建企业级应用
```

### 3.3 配置 MCP

```
入门实践路线：

Step 1：安装 Claude Desktop
Step 2：添加基础 MCP Server
  - 文件系统 Server（读写文件）
  - 搜索 Server（搜索网页）
Step 3：体验增强后的 AI 能力
Step 4：尝试更多 MCP Server
Step 5：学习创建自己的 MCP Server
```
