# Windows 10 悬浮时钟组件

这是一个直接运行在 Windows 10 上的透明悬浮时钟。它的所有功能和您 Mac 上的版本一模一样，包含了：
- 单击拖拽移动位置
- 鼠标悬停显示隐形边框
- 右下角拖动自由修改大小（字体自适应）
- 完美透明背景和置顶
- 颜色拾取记忆与窗口位置保存

## 运行方法

### 方法一：直接运行脚本 (推荐)
如果您或您的目标 Windows 电脑上已经安装过 Python：
1. 双击运行 `windows_floating_clock.py` 文件（或者右键在终端中通过 `python windows_floating_clock.py` 运行）即可。
系统内置支持，不需要安装任何第三方库庞大依赖！

### 方法二：打包为独立EXE (如果没有安装Python)
如果要在没有任何环境的 Windows 10 电脑上双击就跑，只需要在自带 Python 的电脑上双击运行文件夹内的 `build_windows_exe.bat` 脚本即可。
它会自动将时钟打包为您熟悉的单一、绿色的 `悬浮时钟.exe` 独立程序！

> 注：因为架构隔离，此 EXE 需要在 Windows 电脑上点击该脚本进行一键生成（Mac这里负责提供跨平台的完善源码方案）。
